# Принципы проектирования: KISS, DRY, YAGNI и другие

## KISS — Keep It Simple, Stupid

**Суть:** Делай максимально просто. Каждый элемент UI должен иметь ясную цель.

### Применение к дизайну мобильных приложений

**Правило "Less is More":**
- Убирай всё, что не помогает пользователю решить его задачу
- 2-3 секции максимум на экран — больше перегружает
- Каждый элемент должен отвечать на вопрос: "Зачем он здесь?"

**Экраны:**
- Один экран = одна задача (или одна группа связанных задач)
- Не показывай 10 кнопок — покажи 2-3 главных, остальные спрячь в "ещё"
- Заголовки: короткие и понятные, без "умных" формулировок

**Навигация:**
- Максимум 5 пунктов в bottom nav
- Глубина навигации: не более 3 уровней (List → Detail → Edit)
- Каждый тап должен вести куда-то конкретно — никаких промежуточных экранов

**Тексты и микрокопия:**
- Ясность важнее красоты: "Сохранить" лучше чем "Подтвердить изменения"
- Кнопки: глагол + объект ("Удалить контакт", "Создать сделку")
- Ошибки: что случилось + что делать ("Нет интернета. Проверьте подключение")

**Формы:**
- Минимум полей — запрашивай только необходимое
- Один столбец на мобильных
- Авто-определение типа клавиатуры (числовая для телефона, email для email)

### Антипаттерны KISS
- Экран с 15+ элементами без визуальной иерархии
- Меню с 8+ пунктами без группировки
- Модалка внутри модалки внутри bottom sheet
- Форма на 20 полей без разбивки на шаги

## DRY — Don't Repeat Yourself

**Суть:** Каждый кусок логики/дизайна существует в одном месте.

### Применение к дизайну
- **Design tokens:** Цвета, шрифты, отступы — определяются один раз, используются везде
- **Компоненты:** Карточка контакта выглядит одинаково в любом списке
- **Паттерны:** Bottom sheet всегда с одинаковой структурой (drag handle → title → content → CTA)
- **Анимации:** Стандартный набор (page entry, list stagger, card entrance) переиспользуется

### Практика
```
НЕ: Каждая страница имеет свой стиль карточки
ДА: GlassCard — единый компонент, настраиваемый через параметры
```

## YAGNI — You Ain't Gonna Need It

**Суть:** Не делай то, что не нужно прямо сейчас.

### Применение к дизайну
- Не добавляй фильтры, если в списке < 10 элементов
- Не делай поиск по странице с 5 пунктами меню
- Не проектируй "на будущее" — проектируй на текущие требования
- Анимация нужна для UX-фидбека, а не для красоты ради красоты

### Антипаттерны YAGNI
- Dashboard с 20 метриками, когда пользователю нужны 4
- Drag & drop на списке из 3 элементов
- Тёмная тема для MVP-приложения

## SOLID в контексте UI

### Single Responsibility (Единая ответственность)
- Один компонент = одна задача
- `_ContactCard` отображает контакт, не управляет навигацией
- Контроллер загружает данные, UI их отображает

### Open/Closed (Открыт для расширения, закрыт для модификации)
- Стили через `.copyWith()` — расширяем, не меняем базу
- Новый тип карточки = новый компонент, не правка существующего

### Interface Segregation (Разделение интерфейсов)
- Bottom sheet для создания ≠ bottom sheet для выбора
- Не делай "универсальный" компонент, который делает всё плохо

## Progressive Disclosure (Прогрессивное раскрытие)

**Суть:** Показывай только то, что нужно сейчас. Остальное раскрывай по запросу.

### Уровни раскрытия
1. **Основной экран** — 3-5 ключевых действий
2. **По запросу** — "Показать ещё", раскрытие секций
3. **Глубокое погружение** — полная форма, расширенные настройки

### Примеры в мобильных приложениях
- Settings: базовые настройки видны, "Дополнительно" скрыто
- Фильтры: основные 3-4 видны как chips, полный набор — в развёрнутой панели
- Формы: обязательные поля видны, опциональные за "Добавить поле"
- Списки: 10-30 элементов, потом "Загрузить ещё"

### UI-паттерны раскрытия
- Accordion (аккордеон)
- "Show more" link
- Expandable cards
- Tabbed content
- Bottom sheet с доп. опциями

## Правило 60-30-10 для цветов

- **60%** — доминантный цвет (фон, основные поверхности)
- **30%** — вторичный цвет (карточки, секции)
- **10%** — акцентный цвет (кнопки, индикаторы, важные элементы)

---

## Правило 3 кликов

Пользователь должен добраться до любого контента максимум за 3 тапа от главного экрана.

```
Home → Contact List → Contact Detail  (2 тапа)
Home → More → Settings → Language     (3 тапа)
```
