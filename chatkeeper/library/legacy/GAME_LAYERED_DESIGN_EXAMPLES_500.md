# 500 Layered Game UI Design Examples

**Purpose:** расширение игровой дизайн-базы ADS: 500 коротких референс-карточек для сложных, красивых, слоистых экранов мобильных и PC/mobile игр.

**Last updated:** 2026-05-21

## How To Use

- Для нового игрового проекта: выбери жанр, затем 3-5 карточек как визуальный ДНК экрана.
- Для Speckit: копируй ID карточек в spec/research, чтобы дизайн оставался конкретным.
- Для Flutter/ADS: применяй слойность через PageLayout + AppContainer + AppText + CustomBounceEffect + flutter_animate.
- Это не набор ассетов и не копирование чужих экранов; это безопасные композиционные паттерны, вдохновленные современными игровыми UI.

## Source Direction

Тренды сверены с публичными направлениями: Apple Design Awards 2025, Google Play Best of 2025, App Store Awards 2025, Game UI Database, а также с уже существующими локальными базами GAME_UI_DESIGN_REFERENCE и MOBILE_GAME_UI_PATTERNS.

Reference pointers:
- Apple Design Awards 2025: https://developer.apple.com/design/awards/
- Google Play Best of 2025: https://blog.google/products/google-play/best-apps-games-2025/
- App Store Awards 2025: https://www.apple.com/newsroom/
- Game UI Database: https://www.gameuidatabase.com/

## Composition Formula

Every card below follows the same mental model:

`world/art layer -> atmosphere/depth layer -> information layer -> action layer -> feedback layer`

## Safety Rules For Generation

- Do not clone exact UI from a named game; combine 2-3 cards and re-theme.
- Keep gameplay readable first: decorative layers must never cover controls, counters, or timers.
- Use accessibility variants for Reduce Motion, high contrast, and text scaling.
- Budget effects: one heavy blur/particle system per screen, then cheaper shadows, gradients, and opacity layers.
- Every generated screen still follows ADS rules: AppColors, LayoutStyle, .sp sizes, i18n, library/part components, CustomBounceEffect.
