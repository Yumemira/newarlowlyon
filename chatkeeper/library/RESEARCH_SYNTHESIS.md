# Что извлекать из исследования

Ссылки SRC ведут к первичным карточкам в research/SOURCES.md. Ниже — наша интерпретация для Погонщика, а не универсальные выводы авторов.

| Направление | Источники | Как использовать в приложениях |
| --- | --- | --- |
| Движение объясняет результат | SRC-008, SRC-038, SRC-047 | У выразительного эффекта есть действие, смысл и конец. Базовые частые действия быстрые; редкий значимый результат допускает богатую сцену. |
| Прямое предметное управление | SRC-044 | Превращать ввод в работу с объектом: поворот, привязка, сравнение, сборка. Состояние меняется наглядно; точный ввод остаётся доступен. |
| Физический характер | SRC-030, SRC-047 | Менять не только длительность, но и кривую, дистанцию и отдачу. Для точного инструмента — затухание; для игрушечной сборки — ограниченная пружина. |
| Выразительные входы | SRC-005, SRC-112 | Маски и параллакс подходят для особого раскрытия сцены. Не превращать чтение и переключение вкладок в бесконечный аттракцион. |
| Видимая навигация | SRC-085, SRC-111 | Не прятать все 4–6 разделов ради необычного меню и не задерживать появление нужного текста. Разнообразие достигается и композицией, материалом, предметным взаимодействием. |
| Предметные формы | SRC-218 | Короткий связный ввод может восприниматься как действие, но само переоформление полей ещё не полезная игровая механика. После ввода нужен видимый результат. |
| Персонажи и реактивная графика | SRC-009, SRC-110 | Персонаж или объект отвечает на реальные действия и состояния. Не выбирать runtime по форумной догадке; проверять официальную документацию и проектные зависимости. |
| Ручная выразительность | SRC-232 | Варьировать иллюстрацию, контур и материал, сохраняя читаемые подписи и устойчивую сетку. Не превращать рукотворность в случайную грязную фактуру. |
| Повторяемые эффекты | SRC-291, SRC-293 | Форумы дают полезные возражения: эффект, приятный один раз, может раздражать при сотом повторении. Это гипотеза для проверки, не доказанный универсальный закон. |
| Общие токены | SRC-122 | Внутри приложения согласовывать время и кривые по смысловым ролям; между приложениями выбирать разные семейства движения. |
| Уменьшенное движение | SRC-091 | Сохранять смысл действия в reduced motion, а не просто убирать обратную связь. |

## Пять различимых направлений одной партии

Это примеры выбора, не записи о созданных приложениях:

- Мастерская: Blueprint workshop + рабочая сцена с инспектором + магнитные привязки + техническая типографика.
- Полевой помощник: Botanical fieldbook + рисунок с метками + спокойное раскрытие + бумажные подписи.
- Звуковой инструмент: Retro instrument + шкалы и ручки + затухающая реакция + табличные цифры.
- Творческий конструктор: Clay playground + сцена с инвентарём + сборка + мягкие объёмные формы.
- Коллекционная утилита: Museum labels + полки объектов + сопоставление вариантов + тихие непрерывные переходы.

Не выбирать всем пяти бежевые карточки с разными иконками или всем пяти CIN-MOT киноэффекты. Для другого набора задач направления пересмотреть по назначению.
