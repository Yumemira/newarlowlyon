# Библиотека решений Погонщика

Начни с [правил выбора](SELECTION.md). Для поиска используй `python3 chatkeeper/library/query.py search "cinema dark" --limit 6` из toolkit; для деталей — `show S024 L016`, для недавних сочетаний — `history --limit 6`. Выдача поиска — короткие карточки с путями; полные записи открывай только по выбранным ID. Таблица ниже — карта категорий, не список для полного чтения. Не печатай каталоги целиком и не ищи общие слова по полным JSON-записям: такая выдача включает ненужные подробности.

История выбора хранится локально в `usage.json`. После клонирования команда `history` возвращает пустой список до первого резервирования.

Это библиотека рецептов и исследовательских заметок. Она не является готовым Flutter-пакетом, набором скачанных ассетов или доказательством визуальной проверки всех демо.
