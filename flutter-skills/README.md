# Скиллы для разработки Flutter-приложений

- Разработка и выпуск — `pogonshchik`, `flutter-dart`, `create-todo`, `todo-codogenerator`, `todo-release`, `collect-app-screenshots`, `release-check`.
- Дизайн и графика — `rescrinit`, скиллы для 2D-ассетов и анимаций, Blender-блокинга, игровых зданий и настройки камеры.
- Игры — Flame, Bonfire, Forge2D, Tiled, прототипирование механик и проверка игрового качества.

Каждый каталог содержит `SKILL.md` и вспомогательные файлы из исходного скилла. Это копии для хранения в репозитории. Проектные скиллы и команды Spec Kit находятся в `.agents/skills/`.

`pogonshchik` использует [библиотеку дизайна](../chatkeeper/library/INDEX.md) из этого репозитория. История выбора и координация проектов хранятся локально. Для запуска также нужен доступ к чатам Codex. Некоторые скиллы используют локальные пути и инструменты, описанные в их `SKILL.md`.
