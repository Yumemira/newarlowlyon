# Построение деталей Blender

Использовать принятое разбиение на части и правила проекта. Этот навык отвечает за геометрию, не требует повторного разбора референса или полной приёмки на каждой правке.

- Каждая конструктивная деталь — отдельный Object с независимым mesh datablock и именем по функции. Не склеивать детали через Union, Join или remesh. Пересечение отдельных объёмов допустимо по конструкции.
- Сначала задать размеры и ориентацию примитива. До настройки зависимых модификаторов выполнить Apply Rotation & Scale, сохраняя мировую геометрию и Location. Для `bpy.ops.object.transform_apply(location=False, rotation=True, scale=True)` нужны Object Mode, активный объект и выделение только целевой детали. Проверить единичный scale и нулевое вращение с числовым допуском.
- Для отверстий, выемок и срезов использовать Difference с явно назначенным объектом-резаком. Резаку дать имя по функции выреза; подготовить его трансформации. При сбоях проверить замкнутость, нормали, пересечение и совпадающие поверхности; при необходимости выбрать `EXACT`.
- Сохранить резак, скрыть его от рендера и обычного просмотра, оставив вычисление выреза рабочим. По умолчанию Difference не применять к сетке.
- Для округлых краёв и сторон использовать Bevel на детали, если форма допускает. Задать нужные рёбра, ширину и сегменты, а не скруглять всё автоматически. До Difference он меняет исходную форму, после может скруглять вырезы. Сохранить модификатор редактируемым; проверить самопересечения. Для неподходящей крупной кривой выбрать другой примитив.
- Не деформировать базовые прямые плоскости ради неровностей рисунка. Скругление не отменяет прямоугольность базовой конструкции. Все ракурсы получать из одной геометрии.
- После дальнейшего изменения трансформаций перепроверить стек. В существующей сцене не обнулять их вслепую: сохранить новую версию и сравнить вычисленную форму до и после. Не заменять ручные правки старой генерацией.

Передать сохранённую сцену и перечень изменённых деталей/модификаторов. Не объявлять файл принятым только из-за успешного исполнения Python.
