# Разбор формы для 3D

Результат — компактное решение по геометрии для последующего моделирования. Если разбор уже принят и форма не меняется, использовать его, не анализировать картинку заново.

- Рассмотреть доступный референс. Выделить главные массы, стыки, повторения и характерные пустоты. Для каждой конструктивной части выбрать примитив, относительные размеры и положение; указать нужные вырезы и скругления. Не дробить объект ради количества деталей.
- Различать наблюдаемое, предполагаемое и исправленное. Не заявлять абсолютный размер, точную глубину или скрытую конструкцию без данных.
- Оценить проекцию и направления осей. Прямой угол в 3D обычно не выглядит прямым на перспективной картинке. Не подменять исправлением геометрии ошибку камеры.
- Для логически прямоугольной конструкции принять прямые рёбра, плоские грани, параллельные противоположные стороны и углы 90°. Локальную кривизну и несогласованные направления рисунка исправлять. Сохранять намеренные скаты, сужения, наклонные опоры и кривые; обосновать неоднозначные исключения.
- Если нужна измеримая подгонка камеры, подключить доступный `calibrate-game-camera`. Его ортографический solver не решает произвольную перспективу; не подгонять искажённые линии любой ценой.

Записать части, геометрические допущения, исправленные искажения и гипотезу камеры в существующую карточку объекта. Не создавать второй отчёт, если карточки достаточно. Продолжать по разумным допущениям; уточнять только то, без чего нельзя выбрать существенную форму. Разбор сам по себе не завершает запрос на готовую модель.
